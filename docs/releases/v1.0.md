# 🚀 WebOS 1.0 "Ashen"

The first stable WebOS release. A fast, monochrome Gentoo desktop built for
gaming, with a custom LTS kernel, a one-screen installer, and updates that keep
working after install.

> **Base:** Gentoo · OpenRC + elogind · no systemd  
> **Kernel:** `6.12.0-webos` LTS + WebOS tuning  
> **Desktop:** Hyprland + the Ashen mono rice  
> **Installer:** `webos-installer` 1.0.0

## 🆕 What's new in the final build

- 🖤 **A single WebOS appearance.** The rounded monochrome bar from the
  reference rice is now the live-session default and every installed account.
  Noctalia, niri and the alternate dotfiles page are gone.
- 🧩 **Cleaner installer.** Profiles are WebOS (Hyprland), opt-in Plasma, and
  TTY-only. Flatpak is on by default; `zenity` is included for game launchers.
- ⌨️ **Keys that match the muscle memory.** `Super+Q` opens kitty, `Super+C`
  closes a window, `Super+Shift+Escape` exits Hyprland, `Super+Shift+S` is the
  screenshot/snip key, and the old special-workspace binding moved to
  `Super+CTRL+S`.
- 📸 **Screenshots that just work.** `webos-shot` saves a selected region to
  `~/Pictures/Screenshots` and copies it to the clipboard. Print, Shift+Print
  and Super+Print still cover clipboard, window and full-output captures.
- 🪟 **Transparency restored.** kitty owns its alpha and the compositor no
  longer stacks a second opacity over it. The framed fastfetch card is back and
  stays aligned with the braille WebOS logo.
- 🖥️ **Plasma is optional.** Regular Plasma 6.8 (Wayland) lives in the opt-in
  `@plasma` set. Non-Plasma installs remove it and its session file, while
  keeping `systemsettings` for the Hyprland settings menu.
- 🛠️ **Maintainer handoff included.** `docs/MAINTENANCE.txt` documents the
  overlay-sync update path, kernel revisions and session rules for future
  maintenance.

## 💿 Install

Download the split ISO parts, then reassemble and verify:

```sh
cat webos-1.0-Ashen-amd64.iso.part-* > webos-1.0-Ashen-amd64.iso
sha256sum -c SHA256SUMS.txt
```

Flash the resulting ISO with Ventoy, Rufus, balenaEtcher or `dd`. UEFI is the
recommended path; BIOS is supported.

After boot, the installer asks for the disk, filesystem, account and features.
Everything else — session seeding, rice, kernel, GRUB, services — is handled
for you. ✅

## 📌 Good to know

- 🧱 **64-bit only.** No multilib, so native Steam is not included. Flatpak
  Steam works because the kernel still provides 32-bit emulation.
- ⏱️ **Not bit-for-bit reproducible.** The Gentoo snapshot, third-party
  overlays and image timestamps move between builds. The published
  `SHA256SUMS.txt` is the authoritative check for this release.
- 🌐 **Updates need the network once.** `webos-update` pulls the WebOS overlay
  from GitHub before resolving updates; `--no-sync` skips that step.
