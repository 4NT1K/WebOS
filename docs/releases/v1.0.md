# WebOS 1.0 (Ashen)

First stable release. Rebuilt from the 1.022 tree with the final installer,
session, rice and updater fixes.

## Fixed

- **One session at login.** The installer clears `/usr/share/webos/sessions`
  and links only the desktop chosen in the wizard. SDDM no longer shows a list
  of every installed desktop, and `/var/lib/sddm/state.conf` is seeded with
  that session.
- **Plasma is opt-in.** `kde-plasma/plasma-meta` and friends were in the
  default `@desktop` set, so every Full/Noctalia image inherited Plasma and a
  "Plasma (Wayland)" login entry. They now live in a separate `@plasma` set;
  non-Plasma installs unmerge Plasma (keeping `systemsettings`, which the
  Hyprland settings menu uses) and delete its session file. The Plasma profile
  still installs and themes regular Plasma.
- **Keybinds follow the request.** `Super+Q` opens kitty, `Super+C` closes the
  window, `Super+Shift+Escape` exits Hyprland (no more conflicting `Q`), and
  `Super+Shift+S` is the screenshot/snip key. The old "move to special
  workspace" binding is now `Super+CTRL+S`.
- **Screenshot/snip.** `webos-shot` saves a selected region to
  `~/Pictures/Screenshots` and copies it to the clipboard. Print, Shift+Print
  and Super+Print still cover clipboard/window/output captures.
- **zram actually starts.** The kernel fragment used the ignored
  `CONFIG_ZRAM_DEF_COMP_ZSTD` symbol; it now enables `CONFIG_ZRAM_BACKEND_ZSTD`
  and defaults to zstd. The boot glue falls back to lzo-rle and logs failures
  to `/var/log/rc.log`; `--doctor` checks that swap is active.
- **ananicy-cpp is enabled.** Gentoo names the service `ananicy-cpp.initd`;
  the installer probes that name, adds it to the default runlevel and starts
  it. `--doctor` checks it.
- **Privacy on the mono bar.** The LAN IPv4 address and battery percentage are
  gone; the power menu is unchanged. The default bar no longer prints an IP
  either.
- **Transparency restored.** kitty owns its alpha (`background_opacity`
  0.80-0.82) and the compositor no longer multiplies a second opacity over it,
  which used to make the terminal look opaque. The framed fastfetch card is
  back, and `webos-fastfetch` sizes the frame from the visible line width so
  ANSI colours and the braille logo stay aligned.
- **`webos-update` handles the kernel.** `sys-kernel/webos-kernel` is not in
  `@world`, so `@world` alone never updated it. The updater now refreshes the
  local WebOS overlay from GitHub (it is `auto-sync = no`), emerges the kernel
  explicitly, regenerates GRUB when a new image lands in `/boot`, and reports
  that a reboot is needed. New flag: `--no-kernel`. Kernel security fixes can
  now be shipped as an ebuild revision — `webos-update` on each machine picks
  them up without an ISO rebuild.
- **Docs and cleanup.** `WEBOS-INFO.txt` now documents the real installer log
  path (`/var/log/webos-install.log`), the opt-in desktops, the new keys and
  the update behaviour; stale rice-manifest entries for removed
  `hyprland.conf`/`webos-colors.conf` are pruned.
- **Pointer acceleration** remains off (`accel_profile = flat`,
  `force_no_accel = true`).

## Assets

- `webos-1.0-Ashen-amd64.iso.part-00 … part-02` — split ISO
- `SHA256SUMS.txt` — checksums for the parts
- `README.txt` — reassembly instructions

Reassemble and verify:

```sh
cat webos-1.0-Ashen-amd64.iso.part-* > webos-1.0-Ashen-amd64.iso
sha256sum -c SHA256SUMS.txt
```

Write the ISO to a USB stick with Ventoy, Rufus, balenaEtcher or `dd`.
