# WebOS 1.03.3 "Ashen" — bootable 6.12.119 + corrected fallback

This release supersedes `v1.03.2`. The kernel package installed correctly, but
the resulting initramfs could not produce a usable desktop because the NVIDIA
kernel modules were never rebuilt for `6.12.119`.

| | |
|---|---|
| Installed identity | WebOS 1.03 (Ashen) — unchanged |
| Git tag | `v1.03.3` |
| Kernel | `6.12.119-webos` (Linux 6.12 LTS) |
| Delivery | WebOS overlay + `webos-update` |

## What broke in v1.03.2

`sys-kernel/webos-kernel-sources` installs a stable `/usr/src/linux-6.12` tree
but deliberately removes `.config`, `Module.symvers`, and `vmlinux`. The
`webos-kernel` ebuild also left `/lib/modules/6.12.119-webos/build` pointing at
a `/usr/src/linux-6.12.119-webos` directory that was never created.

During `@world`, `x11-drivers/nvidia-drivers` therefore failed early in
`require_configured_kernel()`. Because the module rebuild never happened,
`/lib/modules/6.12.119-webos/video/` had no `nvidia*.ko` files. Dracut generated
a 20 MB initramfs instead of the previous 92 MB one: no NVIDIA modules and no
GSP firmware. Booting `6.12.119-webos` stalled right after
`Loading initial ramdisk ...`.

The kernel config itself was sound: NVMe, AHCI, Btrfs, initrd/zstd and
devtmpfs were all present, and the two initramfs images were otherwise
identical apart from the NVIDIA payload.

## What changed in v1.03.3

`webos-update` now treats the kernel step as a complete boot-chain rebuild:

1. Copies `/boot/config-${newest}` into `/usr/src/linux-${series}`.
2. Applies the GCC 16 C11 compatibility flags used by the kernel ebuild.
3. Runs `make olddefconfig modules` to regenerate `Module.symvers`.
4. Repairs `/lib/modules/${newest}/build` so it points at the prepared tree.
5. Rebuilds `x11-drivers/nvidia-drivers` from source with
   `SKIP_KERNEL_CHECK=1 KERNEL_DIR=...`, explicitly refusing cached binpkgs.
6. Runs `depmod -a` and regenerates the initramfs for the exact kernel release.
7. Verifies the initramfs actually contains the kernel module tree.
8. Sets `GRUB_DEFAULT` to the newest installed kernel and regenerates GRUB.

The previous kernel remains in the GRUB menu as a manual fallback. The old
behaviour that pinned `GRUB_DEFAULT` to `6.12.0-webos` forever is gone.

`scripts/50-check.sh` now asserts that `webos-update` carries the build-tree
preparation, out-of-tree rebuild, initramfs regeneration, and GRUB default
fix. `webos-update` reports its own version as `1.03.3` in the update log.

## Manual repair

Existing 1.03.2 installs can be repaired without waiting for another update by
running the build-tree preparation, NVIDIA rebuild, and dracut steps above.
The exact pasteable commands are in the release thread; after they complete,
verify that `/boot/initramfs-6.12.119-webos.img` is around 92 MB and contains
`nvidia.ko`, `nvidia_modeset.ko`, `nvidia_uvm.ko`, `nvidia_drm.ko`, and the
`620.73.04` firmware blobs.
