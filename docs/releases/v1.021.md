# 🚀 WebOS 1.021 "Ashen"

A clean maintenance rebuild of the Ashen image. It is built from a fresh Gentoo
stage3 chroot populated only from this repository — not from a maintainer's
installed system — so none of the build host's accounts, browser profiles,
game saves, SSH keys or local overrides end up on the medium. The shipped
software and configuration are the current `main` tree, including the redesigned
music card, the per-core performance panel and full transparency support.

Existing 1.02 systems receive the same tree with one `sudo webos-update`.

> **Base:** Gentoo · OpenRC + elogind · no systemd
> **Kernel:** `6.12.0-webos` LTS + WebOS tuning
> **Desktop:** Hyprland + the Ashen mono rice
> **Installer:** `webos-installer` 1.0.0
> **Theme:** `webos-theme-1.0-r51`

## 🐛 Fixed since 1.02

- **Phantom update badge:** the updater removed retired Vesktop from `world` but not from `/etc/portage/sets/desktop`, so `@world` planned it again on every run. Both places are now cleaned.
- **Cava widget removed:** the top-bar visualizer and its `webos-visualizer` helper were deleted, along with the `media-sound/cava` dependency and Portage set entry. The music pill is centred on its own again.
- **No more stuck track time:** the MPRIS pill no longer shows a static length/position; the card keeps the real elapsed/total bar.
- **Correct seek and volume behaviour:** dragging previews the seek and seeks once on release with no snap-back; volume changes apply live while dragging and only affect Spotify, never the system sink. The mute button is gone.
- **Readable controls:** GTK's blue accent no longer leaks into the seek/volume bars; they follow the cover art in pure black or white with no glow, outline or button box. Artwork detection never blocks the GTK thread.
- **Long titles wrap** onto a second line instead of being cut off.
- **Hyprland config that actually loads:** the rice is a Lua config plus `webos-colors.lua`, verified with `Hyprland --verify-config`; `webos-rice --doctor` no longer reports a false font failure.
- **Session services** (waybar, wallpaper, portals, polkit agent) start reliably, and SDDM shows only the chosen session.

## 📦 Assets

- `webos-1.021-Ashen-amd64.iso` (also published as split `.part-*` files)
- `SHA256SUMS.txt`, `webos-1.021-Ashen-amd64.iso.sha256`, `.b2`, `.asc`

Reassemble and verify:

```bash
cat webos-1.021-Ashen-amd64.iso.part-* > webos-1.021-Ashen-amd64.iso
sha256sum -c SHA256SUMS.txt
```

Flash with Ventoy, Rufus, balenaEtcher or `dd`, boot the live medium, then run
`webos-installer`. See the [complete guide](../WEBOS-COMPLETE-GUIDE.txt) for
installer options and post-install setup.
