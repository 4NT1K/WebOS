WebOS 1.02 "Ashen" — system information
=======================================

RELEASE
-------
- v1.02: fixed release — WebOS-branded (white spiderweb OS logo, no Gentoo welcome/identity leaks; OpenRC boot branding set to WebOS, patched in build scripts).
- Version : WebOS 1.02 "Ashen" (Gentoo/OpenRC, gaming-focused)
- ISO     : webos-1.02-Ashen-amd64.iso (split assets + SHA256SUMS.txt on GitHub)
- Source  : https://github.com/4NT1K/WebOS
- Arch    : amd64, 64-bit only (ABI_X86="64", no multilib)

WHAT'S NEW / NOTABLE IN 1.02
----------------------------
- Fixed webos-theme merge collisions that could ship an ISO without /usr/bin/webos-shell, waybar config, portal prefs or dark-mode defaults.
- webos-settings launcher added; Hyprland offers wdisplays/nwg-displays and hyprctl devices for real display/input detection.
- Portal overrides installed under /etc/xdg-desktop-portal to avoid collisions; Hyprland starts/restarts portals and the polkit agent with fallbacks.
- Terminal fastfetch now shows the WebOS cobweb logo image in kitty (kitty graphics) with themed system info; fastfetch wrapper simplified for reliable rendering.
- Hyprland wallpaper startup/apply made more reliable (hyprpaper preload/wallpaper + daemon timing).
- Waybar (top bar) improved: frosted-glass transparency, MPRIS/music module, wallpaper launcher button (waypaper / `webos-wallpaper` fallback), system modules, and more reliable autostart/toggle.
- Smoother Hyprland animations (windows/layers/workspaces) and refined blur/transparency feel.
- Installer split into "System options" and "Extra features": profile/swap/services plus selectable apps/features/shells (Gaming stack, Steam note, Firefox, Discord, Vesktop, OpenCode, Spotify, Waypaper, Fish, Zsh, Flatpak, etc.).
- Theme parity maintained across Hyprland and KDE Plasma (monochrome Deep Black, kitty/fish/fastfetch, Konsole/KWin blur for kitty).
- Hyprland session wiring improved: dbus/systemd user environment import, portal restart on session start, polkit agent fallbacks, and Hyprland portal preferences to support file pickers/auth prompts.

PURPOSE
-------
WebOS ships a "Deep Black" rice: pure-black surfaces, frosted translucency,
white accents. Two desktops in one image: Hyprland (Wayland, default) and
KDE Plasma 6.

SESSIONS
--------
- Hyprland uses xdg-desktop-portal-hyprland/gtk/wlr and a polkit auth agent
  (hyprpolkitagent with fallbacks). KDE apps/duplicates are hidden from
  Hyprland menus to keep sessions separate.
- KDE Plasma uses xdg-desktop-portal-kde and polkit-kde-authentication-agent-1.
- Hyprland  : session "WebOS" in SDDM (also `webos-session` from a TTY)
- KDE Plasma: normal Plasma 6 session in SDDM
- Gamescope : `webos-session --gamescope` (SteamOS-style session)

THEME / RICE
------------
Dark mode defaults are enabled by default (GTK/Qt/session env and Plasma color scheme where applicable).

Commands:
  webos-rice --user            apply the rice to the current account
  webos-rice --system          apply to /etc/skel, /root and every /home/*
  webos-rice --ensure          only fill in missing files (runs at login)
  webos-rice --check           dry run, report what would change
  webos-rice --doctor          diagnose missing theme pieces
  webos-rice --toggle-panel    show/hide waybar
  webos-rice --wallpaper FILE  set the wallpaper
  webos-rice --force           overwrite existing files (keeps .webos-orig)

Rice lives in /usr/share/webos/rice (read-only source of truth). Per-user
copies: ~/.config/{hypr,waybar,wofi,kitty,fish,fastfetch,gtk-3.0,gtk-4.0},
~/.local/share/color-schemes/DeepBlack.colors, ~/.local/share/konsole, and
Plasma configs (kdeglobals/kwinrc/kwinrulesrc).
KDE Plasma: Deep Black scheme, Breeze_Light cursor, custom wallpaper, Konsole
profile/colorscheme matched to terminal theme, and KWin blur/opacity rule for
kitty. Hyprland: white borders, Breeze_Light cursor, blurred/frosted translucent
surfaces, and smoothed animations. Overall palette matches the monochrome
terminal theme (pure black bg, #F2F2F2 fg, #FFFFFF labels, #8C8C8C dim).

TERMINAL / FASTFETCH
--------------------
kitty runs /usr/bin/webos-shell, which prints the WebOS fastfetch card (original
WebOS ASCII art, smooth continuous-line box `┌─┐│└─┘`) then execs $SHELL. Nested
shells do not repeat it. Modules: display, uptime, cpu, gpu, terminal, memory,
disk, packages, shell, datetime.
Theme: pure black (#000000) ~60% opacity with strong blur (frosted glass),
strictly monochrome (fg #F2F2F2, bold/labels #FFFFFF, dim/secondary #8C8C8C,
greyscale ANSI 0–15), thin white bar cursor (no blink), white selection ~20%.
Fish prompt is minimal `~ ❯` in white. Applied to kitty/fish/fastfetch on both
Hyprland and KDE Plasma (KWin blur rule for kitty). UTF-8/ASCII fallback used
for box rendering compatibility.
Manual: `webos-fastfetch`. Config: /usr/share/webos/rice/fastfetch/.

PREINSTALLED / OPTIONAL APPS
----------------------------
Common prebuilt apps: Firefox (firefox-bin), Discord, OpenCode (opencode-bin),
Spotify, Dolphin, KDE System Settings, kitty, waybar, wofi, mako, mpv, imv,
Lutris, Heroic, gamescope, gamemode, MangoHud, vkBasalt, vkd3d-proton.
Additional options may be included/selectable depending on build/installer choices
(e.g. Vesktop, Waypaper, Fish, Zsh, Flatpak).
Wine is NOT included (needs 32-bit). Native Steam is NOT included (see below).

STEAM AND 32-BIT SOFTWARE
-------------------------
This image is 64-bit only. Steam, Wine (32-bit games), winetricks,
protontricks and goverlay need a 32-bit multilib runtime and are not shipped.
The kernel DOES support 32-bit code (CONFIG_IA32_EMULATION=y), so:
  - Flatpak Steam works (recommended today):
      sudo emerge flatpak
      flatpak remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo
      flatpak install flathub com.valvesoftware.Steam
  - Distrobox (Fedora/Arch container) is an alternative.
  - Native Portage Steam requires a multilib rebuild.
A future WebOS build will ship multilib so Steam can be preinstalled.
If selected in the installer, note is written to /etc/webos/steam-unavailable.txt.

UPDATES
-------
`webos-update` (Portage-based updater):
  sudo webos-update              sync repos, rebuild @world, depclean, config updates, flatpak, rice
  sudo webos-update --check      dry run
  sudo webos-update --yes        non-interactive config merges
  --no-sync | --no-flatpak | --no-depclean | --quiet
Log: /var/log/webos-update.log. Updates compile from source unless a binhost is configured.

PACKAGE MANAGEMENT
------------------
Portage + OpenRC. No binary host configured by default, so `emerge` compiles from source.
Repos: gentoo, webos (local overlay at /usr/local/portage/webos) and build-time
third-party overlays as configured; some build-time-only overlays may be disabled
on installed systems under /etc/portage/repos.conf.disabled.
  emerge --sync
  emerge -av <package>
  emerge -avuDN @world
  emerge --depclean
  dispatch-conf

SERVICES (OpenRC)
-----------------
Default runlevel typically includes: dbus, elogind, NetworkManager, syslog-ng,
acpid, webos (local.d glue), ananicy-cpp, irqbalance, display-manager (SDDM).
Optional: bluetooth, sshd, nftables (installer toggles).
  rc-service <name> status|start|stop|restart
  rc-update add|del <name> default

INSTALLER
---------
TUI/GUI-capable installer: `webos-installer` (also ISO boot entry).
Profiles: Hyprland, KDE Plasma, Minimal (console only).
Customization toggles include: gaming stack, Steam note (64-bit image), Firefox,
Discord, Vesktop, OpenCode, Spotify, Waypaper, Fish, Zsh, Flatpak, NVIDIA,
Bluetooth, SSH, firewall, GRUB (subject to image/package availability).
Unattended: `webos-installer -c /etc/webos/install.toml -y` (dry run: -d).
Applies rice for desktop profiles and configures display manager/session defaults.

NVIDIA
------
x11-drivers/nvidia-drivers is installed (open modules). nouveau is blacklisted;
installer adds nvidia-drm.modeset=1 and dracut force_drivers when NVIDIA option
is chosen. AMD/Intel systems ignore it.

TROUBLESHOOTING
---------------
- Theme not applied: `webos-rice --user --force`, then log out/in.
- No waybar: `webos-rice --toggle-panel` or run `waybar`; check `webos-rice --doctor`.
- wofi does not open: launcher, not a daemon — press Super+D.
- Wallpaper missing in Hyprland: ensure `hyprpaper` running (`hyprctl monitors`) and rerun `webos-wallpaper` or `webos-rice --ensure`.
- Portals/auth prompts: confirm session env (Wayland), portal backends installed, and polkit agent running for the session.
- Installer log: /var/log/webos-installer.log. Install config: /etc/webos/install.toml.
- Hyprland log: ~/.local/share/hyprland/hyprland.log
